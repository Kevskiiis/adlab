Overview

This lab simulates the IT environment of Flux Comics, a fictional comic publishing and retail company with ten employees across four departments. I designed and maintain it to practice hands-on Windows infrastructure administration, focusing on Active Directory Domain Services (AD DS), Domain Name System (DNS), security group-based access control, Server Message Block (SMB) file services, and Group Policy Object (GPO) administration.

Lab Scope and Data Disclaimer

Flux Comics isn’t a real company. I made it up just for this Active Directory and Windows lab. All the employees, user accounts, departments, job titles, organizational details, and file server contents are simulated. I’m not using any real employee information, company records, customer data, or confidential business information. The domain ad.comics.internal only exists in my isolated lab.
