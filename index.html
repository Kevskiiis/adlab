Overview

This lab simulates the IT environment of Flux Comics, a fictional comic publishing and retail company. I built it to practice hands-on Windows infrastructure administration across identity, file services, endpoint controls, and networked systems.

Lab Scope and Data Disclaimer

Flux Comics is fictional. Employees, departments, directory objects, and file contents are simulated for educational and portfolio demonstration only. The domain ad.comics.internal exists only inside the isolated lab.

Lab Environment

Platform

HypervisorVMware Workstation Pro
ServerWindows Server 2025 (single Virtual Machine)
ClientsTwo Windows 11 Virtual Machines, domain-joined
NetworkCustom VMnet with bridged connectivity
Server addressingIP address reserved through a DHCP reservation on a router

Lab Constraints

Single serverThe domain controller and file server share one VM because of local hardware limits. This is for the lab only, not a production design.

Technical Documentation Areas

Follow the implementation from the platform it runs on to the identity, access, file-service, and endpoint controls built on top of it.

How centralized endpoint controls are scoped, applied, and validated.

Implementation Status

Status is separated into implemented, in-progress, and planned work to distinguish current configuration from future development.

Implemented

  • AD DS domain structure and Organizational Unit (OU) hierarchy.
  • Ten fictional user accounts aligned to four departments.
  • DoomVault SMB share with folder segmentation and NTFS control model.
  • SMB encryption in transit and Access-Based Enumeration (ABE).

In Progress

  • Security group membership completion and effective access validation.
  • Cross-department file access verification against expected permissions.
  • Additional GPO policy coverage for computers and users.

Planned

  • Automation for account provisioning and group assignment workflows.
  • Expanded endpoint hardening controls and validation procedures.
  • Additional troubleshooting and administration runbook documentation.
